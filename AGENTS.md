# Project instructions

Before changing this workspace:

1. Read `PROJECT_PLAN.md` completely.
2. Preserve the original directory `Beautice - Clinic & Beauty Consultation Website Design (Community)`.
3. Follow the phases and demo constraints in the plan.
4. Do not scaffold all demos at once. Finish and verify the current phase first.
5. Update the status checklist in `PROJECT_PLAN.md` when a phase is genuinely complete.
6. Keep styling implementations separate; share only content, tokens, and asset mappings.
7. Run the relevant build, typecheck, lint, and visual checks before marking work complete.
8. Treat each demo as a complete 8-page website: Home 1, Home 2, About, Services, Gallery, Team, Blog, and Contact. A Home 1-only implementation is not a complete demo.
